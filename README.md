# TravelSync

A full-stack booking and collaboration platform built with React Native, Node.js, Express.js, MongoDB, Socket.io, Redux Toolkit, and Firebase.

TravelSync provides a complete mobile experience with real-time communication, media sharing, notifications, and reliable offline/online handling.

---

## 🚀 Features

### 📱 Mobile Application
- User-friendly React Native mobile application
- Booking and management functionality
- Real-time chat and communication
- Message editing and deletion
- Image/media sharing
- Push notifications
- Offline/online network handling
- Redux Toolkit for state management

### 💬 Real-Time Communication
- Real-time messaging using Socket.io
- Instant message updates
- Message edit and delete functionality
- Media sharing through chat

### 🔔 Notifications
- Firebase Cloud Messaging integration
- Push notifications for important updates and messages

### 🌐 Web/Admin Panel
- Web-based administration interface
- Backend API integration
- Management and monitoring functionality

### 🔐 Backend
- RESTful APIs using Node.js and Express.js
- MongoDB database integration
- Authentication and secure API communication
- Structured backend architecture
